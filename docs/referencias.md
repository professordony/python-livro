# Referências Bibliográficas

## Livros Citados

- **Black Hat Python, 2nd Edition** — Justin Seitz e Tim Arnold (No Starch Press, 2021)
  *Inspiração para a abordagem prática de Python aplicado à segurança.*

- **Hacking: The Art of Exploitation, 2nd Edition** — Jon Erickson (No Starch Press, 2008)
  *Referência para a progressão didática de fundamentos → exploração.*

- **The Hacker Playbook 3: Practical Guide to Penetration Testing** — Peter Kim (2018)
  *Metodologia prática de testes de invasão.*

## Documentações Técnicas

- **Python 3 Documentation** — https://docs.python.org/3/
  *Referência oficial da linguagem.*

- **Paramiko Documentation** — https://docs.paramiko.org/
  *Biblioteca SSH para Python.*

- **Scapy Documentation** — https://scapy.readthedocs.io/
  *Manipulação de pacotes de rede.*

- **CIS Benchmarks** — https://www.cisecurity.org/cis-benchmarks/
  *Padrões de hardening reconhecidos internacionalmente.*

## Ferramentas Mencionadas

- **Nmap** — https://nmap.org/ — Scanner de portas profissional
- **Wireshark** — https://wireshark.org/ — Analisador de pacotes gráfico
- **Metasploit** — https://www.metasploit.com/ — Framework de exploração
- **fail2ban** — https://www.fail2ban.org/ — Prevenção de força bruta
- **Tripwire** — https://github.com/Tripwire/ — Verificador de integridade
- **OSSEC** — https://www.ossec.net/ — HIDS (Host-based Intrusion Detection)

## Artigos e RFCs

- RFC 793 — Transmission Control Protocol
- RFC 2616 — Hypertext Transfer Protocol (HTTP)
- RFC 4251 — SSH Protocol Architecture
- RFC 5246 — Transport Layer Security (TLS)

## Legislação Brasileira

- **Lei 12.737/2012** (Lei Carolina Dieckmann) — tipifica crimes cibernéticos
- **Lei 13.709/2018** (LGPD) — Lei Geral de Proteção de Dados
- **Marco Civil da Internet** (Lei 12.965/2014) — direitos e deveres na internet
