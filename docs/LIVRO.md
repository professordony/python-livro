# Prefácio

Este livro nasceu de uma conversa entre professor e alunos.

"Professor, eu quero aprender Python, mas todos os cursos começam com `print('Olá, mundo')` e eu não vejo como aquilo se aplica ao que eu faço no dia a dia."

Se você é técnico de suporte N1, analista de segurança iniciante, ou um estudante de TI que quer dar o próximo passo, você já deve ter sentido a mesma coisa. Você sabe configurar um switch, entende como um pacote viaja pela rede, já abriu o Wireshark para investigar um problema. Mas quando abre o editor de código, bate aquela sensação de "não sei nem por onde começar".

Este livro é para você.

Nós vamos começar **do zero absoluto** — sem assumir que você sabe o que é uma variável, um loop, ou uma função. Mas, diferente dos cursos genéricos de programação, **cada conceito vai ser ensinado através de ferramentas de segurança**. Você vai aprender `if` porque precisa validar uma senha. Vai aprender `for` porque precisa percorrer uma lista de portas para escanear. Vai aprender hashes porque precisa verificar se um arquivo foi alterado.

No final, você terá construído **seu próprio kit de ferramentas** de cibersegurança — programas que fazem varredura de rede, força bruta, análise de logs, monitoramento de integridade e detecção de invasões. Ferramentas que você pode usar no seu laboratório, nos seus estudos, ou no seu trabalho.

E o melhor: você vai entender cada linha de código. Não vai sair copiando script da internet sem saber o que faz.

Seja bem-vindo. Vamos hacker — e defender — juntos.

*Prof. Dony*

# Introdução

## O que é este livro?

Este é um livro de **programação aplicada à segurança cibernética**. A diferença está no "aplicada": cada capítulo existe para resolver um problema real de segurança.

Você não vai passar seis meses estudando lógica de programação abstrata para depois "ver o que faz com ela". Você vai aprender programação **enquanto** constrói ferramentas de ataque e defesa.

## O que você precisa saber para começar?

**Nada de programação.** Sério. O Capítulo 1 começa explicando o que é um algoritmo.

Mas você precisa:
- Saber usar o computador (ligar, abrir programas, digitar)
- Ter curiosidade para testar as coisas
- Uma máquina com Windows ou Linux (qualquer uma serve)

Conhecimentos básicos de rede (o que é IP, porta, protocolo) ajudam, mas não são obrigatórios — explicamos quando precisamos.

## Como usar este livro

Cada capítulo segue a mesma estrutura:

1. **Objetivos** — o que você vai aprender
2. **Conceito** — a explicação teórica, do jeito simples
3. **Mão na massa** — o código, linha por linha
4. **Exercícios** — para fixar
5. **Resumo** — pontos-chave para lembrar

Não pule os exercícios. Eles são curtos, mas são eles que fazem o aprendizado grudar.

## O que instalar antes de começar?

No Capítulo 5 vamos instalar Python passo a passo. Até lá, você vai escrever algoritmos em papel, fluxogramas, e português estruturado — sem precisar de computador. Sim, de propósito. A lógica vem antes do código.
